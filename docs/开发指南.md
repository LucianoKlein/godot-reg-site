## i18n 翻译怎么加？

首页中英文是两个独立组件，文案直接写在组件里：
- 中文 → `HomeZh.tsx`
- 英文 → `HomeEn.tsx`

子页面（登录、课程列表、播放器）用组件内的 `dict` 对象：

```tsx
// 示例：组件内定义翻译
const dict = {
  zh: { title: "登录", submit: "提交" },
  en: { title: "Login", submit: "Submit" },
};

// 通过 useParams 拿到 locale
const params = useParams();
const locale = params.locale as string;
const t = dict[locale] || dict.zh;

// 使用
<h1>{t.title}</h1>
```

子组件（QuizModal、NotesPanel 等）通过 `locale` prop 接收语言：

```tsx
// 父组件传入
<QuizModal locale={locale} onPass={...} onClose={...} />

// 子组件内部同样用 dict 对象
export default function QuizModal({ locale = "zh", onPass, onClose }) {
  const t = dict[locale] || dict.zh;
  // ...
}
```

## 常用命令

```bash
yarn dev          # 启动开发服务器
npx next build    # 构建（验证是否通过）
```

## 注意事项

- 所有页面链接必须带 locale 前缀，如 `/${locale}/courses` 而不是 `/courses`
- 样式用 SCSS Modules（`.module.scss`），不要写 inline style
- 颜色变量在 `_variables.scss` 里定义，组件里用 `$color-xxx` 引用
- Mock 数据暂时写在各组件内（`MOCK_*` 常量），后续接 API 时替换
